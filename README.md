# MOMO & CO.

Лендинг семейного спешелти-кафе для мам и детей в Санкт-Петербурге.
Архитектурная editorial-эстетика: кобальтовый акцент, тонкие hairline-рамки, крупная типографика Syne.

## Возможности

- **Живой статус** — «Открыто / Закрыто» и часы в шапке по московскому времени, с учётом будней и выходных
- **Зонирование** — интерактивные вкладки с четырьмя зонами кафе
- **Меню** — фильтр по категориям, карточки генерируются из данных
- **Предзаказ** — плавающая корзина с количеством позиций, переносится в заявку на бронь
- **Бронирование** — встроенная форма и модальное окно (закрытие по Esc и клику на фон)
- **Адаптив** — от 375 px до широких экранов, мобильное меню

## Стек

- HTML5 + [Tailwind CSS](https://tailwindcss.com) (Play CDN)
- Vanilla JavaScript, без сборки и зависимостей
- Google Fonts: Syne, Plus Jakarta Sans, Space Mono

## Структура

```
momo-co/
├── index.html                 # разметка страницы
├── assets/
│   ├── css/
│   │   └── styles.css         # кастомные стили поверх Tailwind
│   └── js/
│       ├── tailwind.config.js # дизайн-токены: цвета, шрифты
│       ├── data.js            # контент: часы, зоны, меню
│       └── main.js            # логика: вкладки, меню, корзина, формы
├── README.md
└── .gitignore
```

Чтобы поменять цены, блюда, тексты зон или часы работы, правьте только `assets/js/data.js`.

## Запуск локально

Достаточно открыть `index.html` в браузере. Или поднять простой сервер:

```bash
npx serve .
```

## Публикация на GitHub Pages

1. Залейте содержимое папки в репозиторий.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

## Заметки

- Формы демонстрационные: данные никуда не отправляются, показывается только окно подтверждения.
- Tailwind Play CDN подходит для прототипа. Для продакшена лучше собрать CSS через Tailwind CLI.
- Фотографии загружаются с Unsplash; если картинка недоступна, показывается заглушка.
